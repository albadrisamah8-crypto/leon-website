Leon Website Project

فكرة الموقع
موقع Leon هو موقع تعريفي بسيط،  بواسطة HTML و CSS.
الهدف منه التدرب على إنشاء صفحة ويب ورفعها على GitHub.

محتويات المشروع 
الصفحة الرئيسية للموقع: index.html 
css : مجلد فيه ملف التنسيق الخاص بالألوان والخطوط والتنسيق.
images: مجلد فيه كل صور الموقع.
webfonts : مجلد فيه الخطوط المستخدمة في الموقع.

أقسام الموقع في index.html
Header: القائمة العلوية وشعار الموقع.
 Landing : القسم الأول والترحيبي في الموقع.
Features : قسم المميزات.
Services : قسم الخدمات.
Portfolio : قسم أعمالنا.
About : قسم من نحن.
Contact: قسم التواصل.
Footer : تذييل الموقع.
